# 超三目並べ (Super Tic-Tac-Toe)

HTML 1ファイルで手軽にブラウザで遊べる、**「被せて・動かして・並べる」進化系3目並べゲーム**です。  
名作ボードゲーム**「ゴブレットゴブラーズ (Gobblet Gobblers)」**のルールを参考に、Webブラウザ上で誰でも手軽かつ直感的に遊べるゲームとして制作しました。  
シンプルな三目並べに「大・中・小のコマ」「相手や自分のコマへの被せ」「盤上コマの再移動」という要素が加わり、高い戦略性と心理戦が楽しめます。

---

## 🎮 1. ゲーム概要

本作品は、名作ボードゲーム「ゴブレットゴブラーズ」のギミックを参考に制作されています。通常の三目並べ（○×ゲーム）と異なり、以下の特徴を持っています：

- **大・中・小のコマ**：各プレイヤーは大（3）・中（2）・小（1）のコマを2個ずつ（計6個）持っています。
- **被せる（スタック）**：空いているマスだけでなく、自分・相手を問わず**より小さいコマの上なら被せて置く**ことができます。
- **盤上のコマの再移動**：新しい手駒を置く代わりに、すでに盤面にある自分のコマを持ち上げて別のマス（空きマスまたは小さいコマの上）へ動かすことができます。
- **自爆のスリル**：盤上のコマを持ち上げて移動させた結果、**下に隠れていた相手のコマが現れて相手の3つ並びが成立してしまう**というスリリングなルールも備えています。
- **勝利条件**：上から盤面を見て、自分のコマを**縦・横・斜めのいずれかに3つ並べたプレイヤーの勝利**です。

## 🕹️ 2. 遊び方・操作方法

### 操作方法
- **直感的なドラッグ＆ドロップ**：
  - 手駒トレイのコマ、または盤面上にある自分のコマ（一番上のもの）を**指やマウスでドラッグ**し、置きたいマスまで運んでドロップします。
  - ドラッグ中、配置可能なマスが明るく光り、マスの上にコマを持ってくると緑色にホバー強調されます。
  - 置けない場所や盤外で離した場合は、自動的に元の位置に戻ります。

### ゲームモード
1. **ひとり（vs CPU）**：
   - コンピュータと対戦するモードです。
   - **難易度設定**：
     - **かんたん**：のんびりランダム多めのAI。
     - **ふつう**：即勝ち手の見逃しがなく、相手のリーチ阻止や自爆回避を行う標準的なAI。
     - **👹 鬼**：2手先まで先読み（Minimax探索）を行い、相手を詰ませる強力なAI。
   - **手番選択**：先手／後手／ランダムを選択可能。
2. **ふたり対戦**：
   - 1台のPCやスマートフォンで、先手と後手が交互にプレイするパス＆プレイモードです。

### その他の機能
- **🎙️ リアルタイム実況アナウンス**：画面中央下に「リーチ！」「ダブルリーチ！」「パックン被せ！」「大型コマ降臨！」など、戦況を熱く盛り上げるライブ実況テロップを表示（リーチ時はアラート音と赤色発光で警告！）。
- **効果音（SE）**：コマを置く音、被せた時の「ポンッ！」という音、リーチ通知音、ファンファーレなどを搭載（🔊ボタンでミュート可能）。
- **ヘルプ（❓ボタン）**：いつでもルールを図解付きで確認できます。

## 💡 3. 工夫した点

コミット履歴および実装において、特にこだわったポイントです：

1. **データ構造と完全ルールの再現 (`commit b6bc92e`)**
   - 原案となったC言語コード（`char map[3][3]` の平面的な固定文字）から、「ゴブレットゴブラーズ」の持つ立体的な被せ合い・再移動ルールを取り入れるため、各マスを配列による**スタック構造**で設計しました。これにより、「被せる」「下にあるコマを保持する」「持ち上げたら下のコマが現れる」という奥深いルールを忠実に再現しました。
2. **手応えのある思考ルーチン（特に「👹 鬼」モード）**
   - ミニマックス法とアルファベータ枝刈りをベースに、盤面のリーチ数・コマのサイズ差・中央の支配度を評価する独自評価関数を実装。相手のダブルリーチを防ぎつつ、自分の勝ち筋を作る本格的なAIを実現しました。
3. **外部ファイル不要の単一ファイル完結（Web Audio API & CSSグラフィック）**
   - 画像ファイルや音声ファイルを用意することなく、HTMLファイル1つをダブルクリックするだけでどこでも動作します。
   - ポップな効果音はすべて **Web Audio API の周波数合成**で生成し、可愛いモンスターのコマもすべて **CSS のグラデーションと擬似要素**で描画しています。

## 🔄 4. 作りながら変えた点・試行錯誤

コミット履歴に沿った主な改善・変更の経緯です：

1. **ゲーム名称の決定 (`commit b6bc92e` 付近)**
   - 「ゴブレットゴブラーズ」のルールを参考にしつつ、誰にでも直感的に「進化した三目並べ」であることが伝わるよう、タイトル表記を**「超三目並べ」**に決定・統一しました。
2. **クリック操作からドラッグ＆ドロップへの全面刷新 (`commit c3cc96b`)**
   - 最初は「コマをクリックして選択 → マスをクリックして配置」という2段階クリック方式でしたが、「実際にコマを掴んでマスへ運ぶ方が圧倒的に直感的で楽しい」という観点から、**Pointer Events API を用いたドラッグ＆ドロップ操作**へ変更しました。PCマウスでもスマートフォンタッチでも同じように滑らかに追従します。
3. **盤面コマの再移動バグの修正 (`commit 2946030`)**
   - 初期のDnD実装時、一度手駒から盤面に置いたコマが動かせなくなる不具合が発生しました。
   - 原因は、手駒トレイで使用済みにした際のフラグ（`used: true`）が盤面上のコマにも引き継がれ、CSSの `pointer-events: none` によってタッチ判定が無効化されていたことでした。トレイ内と盤上の状態管理を明確に分離することで、盤面コマの再移動をスムーズに行えるようにしました。
4. **ドラッグ中の残像バグ解消と「下のコマが現れる」演出 (`commit 57024f5`)**
   - 盤面のコマを動かす際、元のマスに薄い半透明のコマ（残像）が残ってしまっていた問題を修正しました。ドラッグ開始と同時に移動元のコマを完全に不可視（`visibility: hidden`）にし、手で持ち上げた感覚をリアルに再現しました。
   - さらに、重なっているマスから上のコマを持ち上げた際、**「下にあるコマ」が顔を出すリアルなレイヤー描画**を導入し、隠れていた相手のコマが現れて自爆するスリルを視覚的にも楽しめるようにしました。
